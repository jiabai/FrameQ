FrameQ v0.3.0 是面向个人开发、少量用户和开源工具场景的稳定桌面版本，支持 Windows x64、macOS Intel 和 macOS Apple Silicon。

## 主要改进

- **本地媒体文件导入**：通过 Rust 原生选择器拾取本地视频/音频，使用不透明选择 token，把所有源完整路径挡在 React、持久化、日志和云端之外。
- **可选 SenseVoiceSmall-ONNX 与按需下载**：新增可选 `funasr_onnx` 运行时，按所选模型按需下载到 app-local data；启动时不自动下载，取消或失败不创建任务。
- **流式 ONNX VAD 与 fail-closed 转写契约**：任何 VAD、音频或分块准备失败即为终态失败，不再回退到整段音频路径。
- **文字稿解剖**：智能提炼工作区新增第四张 target 卡片，对已保存文字稿做结构化拆解。每次调用独立确认、有界额度。
- **内置 ONNX 运行时完整性**：打包 worker 内置所需 ONNX 运行时 wheels。

## macOS 首次打开

macOS DMG 使用 ad-hoc 签名，未经过 Apple notarization。从 GitHub 下载后，需在系统设置 → 隐私与安全性中找到拦截提示，点击"仍要打开"。

## 已知限制

- macOS watchdog、locale/layout 物理验收、本地媒体导入和 ONNX VAD 流式均未在真实 macOS 主机实测。
- AI 输出语言是 prompt 约束，供应商仍可能返回其他语言。
- 外部视频平台页面或接口可能变化，公开链接下载能力仍受平台可用性影响。
