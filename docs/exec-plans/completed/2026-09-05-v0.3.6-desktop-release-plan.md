## Surprises & Discoveries

Evidence: The numeric-format fix and subtitle downloader are newer than v0.3.5. A real subtitle-only call returned 262 en-US segments, identical to directly fetched SRT, without loading ASR libraries.

Evidence: Concurrent local Rust/frontend/worker execution exhausted memory; isolated worker and frontend reruns passed without source changes. Rust rerun uses `-j 1 -- --test-threads=1`.

Evidence: Project policy requires post-publication ledger synchronization. Any ledger-only follow-up commit must leave released runtime sources byte-identical and must not move an already published tag.

## Decision Log

Decision: Use v0.3.6 and retain draft-first three-platform build workflow. Rationale: next available patch release, existing distribution process and explicit user authorization. Date/Author: 2026-09-05 / User + Codex.

Decision: Do not deploy production server or migrate its database as part of desktop publication. Rationale: release includes compatible client behavior; production deployment is a separate operation. Date/Author: 2026-09-05 / Codex.

## Outcomes & Retrospective

The v0.3.6 desktop release is published with the three-platform artifacts from the tagged runtime source. Local and hosted validation passed, including packaged-worker parity, server migration/preflight/restore, and macOS process supervision. Residual risk: clean-machine Windows and macOS native UI smoke are not separately performed for this release; public-platform availability and deployed server capability remain external dependencies. The v0.3.6 tag remains the exact runtime commit; the post-publication ledger/docs synchronization is a separate main commit.
