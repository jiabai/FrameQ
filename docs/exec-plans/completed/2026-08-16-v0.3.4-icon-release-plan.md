# FrameQ v0.3.4 Icon Release Plan

## Goal

Publish the updated desktop icon assets as a stable v0.3.4 patch release without mixing the
unrelated working-tree changes already present in the repository.

## Scope

- Include the updated tracked assets under `app/src-tauri/icons/` used by the Tauri desktop bundle.
- Synchronize all desktop release version sources to `0.3.4`.
- Publish Windows x64 updater artifacts and both macOS DMGs through `desktop-release.yml`.
- Do not change desktop processing behavior, model behavior, server behavior, or private data
  packaging boundaries.
- Do not include `.gitignore`, `AGENTS.md`, `.openclaw-attachments/`, or unrelated plan changes.

## Progress

- [ ] Version sources and release notes prepared.
- [ ] Local release-version and focused app checks pass.
- [ ] Commit and `v0.3.4` tag pushed to `origin`.
- [ ] Desktop Release workflow completes for Windows, macOS Intel, and macOS Apple Silicon.
