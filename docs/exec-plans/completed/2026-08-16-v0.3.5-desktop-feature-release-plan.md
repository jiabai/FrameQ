# FrameQ v0.3.5 Desktop Feature Release Plan

## Goal

Publish the post-v0.3.4 desktop patch release containing the verified Motion experience and
Windows ASR model-download startup recovery.

## Scope

- Include the implemented Motion presentation changes and their focused/browser regressions.
- Include the Windows app-local VC++ runtime staging and worker startup preflight fixes.
- Preserve the lightweight installer boundary: no ASR weights, LLM keys, cloud models, or private
  user configuration in the installer.
- Do not claim a new desktop icon change in this release; the refreshed desktop icon assets were
  already published in v0.3.4.
- Exclude `.openclaw-attachments/` and generated Android/iOS icon directories not referenced by
  the desktop bundle.
