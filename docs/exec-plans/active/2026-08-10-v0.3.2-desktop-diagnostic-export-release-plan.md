# FrameQ v0.3.2 Desktop Diagnostic Export Release Plan

## Goal

Publish the merged desktop diagnostic export feature as v0.3.2 without moving or replacing the
already-published v0.3.1 tag.

## Scope

- Include the merged `codex/desktop-diagnostic-export` work: contract v8, bounded Rust-owned
  diagnostics, local ZIP export, Settings and model-failure entry points, and three-language UI.
- Keep v0.3.1 behavior and its release notes as historical record.
- Do not package ASR weights, LLM keys, cloud models, or user-private configuration.
