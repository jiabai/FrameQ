## 残余风险

- 更新器不为相同版本号推送，装过 11-05 首版或 11-06 重发版 v0.5.0 的用户必须手动重装。
- 删除 release 会移除 8 个资产（含 3 个版本绑定的 PyTorch 运行时组件），`desktop-release.yml` 每次 tag push 会重新上传；发布后需要确认资产名集合与签名。
- 本次改了 macOS Swift 源码，本机没有 Swift 工具链，macOS 作业是首次编译；打 tag 前应先在托管 macOS 环境验证，避免删掉 release 后遇到构建失败。
- `macos-intel-acceptance.yml` 是手动触发，不随 tag 自动运行；macOS 图形交互、Gatekeeper、专项 WebView 检查与公开签名更新链路仍未验证。
- 真实登录页端到端验收需要真实 WebView2 Runtime 与公网；封闭登录路径集合需要随站点维护。
