# FrameQ v0.3.7 Desktop Release

## Intent

Publish the current desktop source as v0.3.7 for the existing personal-development and small-user distribution scope. The runtime change since v0.3.6 is a bounded retry for Douyin share-page parsing plus a neutralized activation-panel title. No local-first, packaging, privacy, or progress-contract boundary changes.

## Boundaries

Only the share-page parse path gains retries; the platform download, audio-preparation, and ASR stages are unchanged. A retry waits a randomized 3 to 10 seconds and the code caps the attempt count, so a failing run is slower but never unbounded, and it never loads ASR libraries, model weights, credentials, private configuration, or local outputs into the release. The retry emits an existing closed-progress event rather than opening the protocol. Self-service activation continues to depend on a compatible deployed server, SMTP, and its existing rollout switch, and the desktop release does not deploy or migrate production server data. Because the self-service activation UI already shipped in v0.3.6, this release is not required for that capability to work.

## Acceptance

Desktop versions agree at 0.3.7; local relevant suites and hosted server/macOS supervision gates pass; Windows installer/updater and both macOS DMGs build from the release tag. Release notes and the task ledger record validation and native smoke limitations. Published runtime source must match main; any subsequent publication-ledger-only commit is explicitly identified.
