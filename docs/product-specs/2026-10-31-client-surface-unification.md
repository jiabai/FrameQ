# 客户端页面与弹窗视觉统一

状态：已按用户确认的执行计划实现，自动化门禁与实际可达入口验收通过；缺少真实条件的原生场景见 `design-qa.md`。当前主界面作为全客户端的视觉基准。

## 目标与依据

让确认、设置、账号、模型、历史与结果界面沿用主界面的中性浅灰、白色、紧凑字号、细线与平面分区。
当前正式工作区及 `build/ui-workspace-preview/` 最新文件提供参考；网页样例的数据与行为不进入产品。

现有主界面的内容、侧边栏、品牌图形、可拖动分隔线、宽度限制、固定切换按钮、保持挂载和约
220ms 收起展开效果继续有效。

## 共享视觉规则

| 项目 | 规范 |
| --- | --- |
| 字体 | 沿用主界面的系统字体；正文、表单与文字操作 14px，弹窗标题 16px/600，分区标题 14px/600，说明 13px，辅助信息 12px。正文行高 1.5–1.65；长篇正文保留阅读所需行高。 |
| 外壳 | 白色背景、1px 中性细边、12px 圆角、单层克制阴影；遮罩仅用低透明度中性色，不使用背景模糊、渐变或饱和度效果。 |
| 分区 | 标签/数值行、细分隔线和自然留白；取消信息分组的装饰性卡片、固定填充高度及多层阴影。 |
| 分隔归属 | 同一边界只绘制一条分隔线。终止正文的事实行、分组及列表末项不再绘制靠近页脚或外壳的底线，并去除额外尾部 padding/margin；真实不同信息行、分区、工具栏和控件边界继续保留。多列布局按实际末行处理，窄窗口改为单列时恢复正常行间分隔。 |
| 间距 | 常规标题/正文水平内边距 20px、垂直间距 12/16px；窄窗口水平 16px；相邻操作间距 8px。 |
| 操作 | 常规文字按钮至少 32px 高、字号 14px，图标按钮 30px、图标 16–18px；主要确认使用实色蓝，危险操作使用明确的危险色。 |
| 表单 | 14px 输入与选择控件、清晰细边；单选/多选的选中状态继续可辨识，保留原生语义、禁用和可见焦点。 |
| 说明 | 隐私、额度、授权、错误和进度保持完整可读；用文字、图标与必要的状态色表达，不依赖装饰性容器。 |
| 滚动 | 标题和操作区可达，正文单独滚动；短内容自然收缩。常规视口留 16px 外边距，窄窗口可收至 12px。长表格、代码与编辑器保留必要边界和自身滚动。 |

尺寸使用 CSS 像素并跟随系统显示缩放。不得通过强制缩放整个弹窗实现紧凑效果。

## 确认页示例

要点总结确认页使用紧凑标题、完整云端内容告知，以及文字稿信息、AI Credits 和输出语言的自然分区。
文字稿、额度、语言使用标签与数值，不各自套入大卡片。确认与取消位于稳定的底部操作区。

已有合法路径使用专门的单行省略区域，保留原文字的辅助技术可读性；必要时沿用原值作为本机悬停提示。
不扩展当前可展示的路径来源，不从 IPC 或日志引入额外绝对路径，不增加路径复制或上传功能。
隐私、计费、错误和授权说明允许自然换行，不能应用路径的省略规则。

## 覆盖范围

| 范围 | 统一要求及保留内容 |
| --- | --- |
| 要点总结确认 | 紧凑标题与说明、平面事实行、单行路径、稳定操作区；保留字数、余额、输出语言和实际调用计费告知。 |
| 文字稿解剖确认 | 六项预览事实改为清楚的标签/数值行；保留任务快照、字符/分段数、调用范围、硬上限、余额及阻止原因。 |
| 启发灵感完整流程 | 档案介绍、六项档案、默认偏好、六步骤与最终确认共用层级；保留选项组边界、当前偏好/长期背景关系、返回/跳过/保存语义。 |
| 生成文字稿确认 | 种子信息、九个平台选项、额度和授权使用共同样式；保留只读预选、请求范围内的平台选择与隐私边界。 |
| AI 结果详情 | 总结、灵感、解剖、空内容、过期、禁用、错误及全屏统一；脑图沿用现有本地 Mermaid 产物，普通 Markdown 代码区域保持其展示语义。 |
| 创作草稿结果 | 预览/编辑/全屏、工具栏、未保存/保存中/失败反馈统一；Markdown、表格、代码和 textarea 保留清晰边界。 |
| 设置全部分类 | 基础、启发灵感、存储、更新、高级五类导航与表单统一；保留模型、缓存、更新、诊断、配置位置及恢复反馈。 |
| 账号与授权 | 账号状态、登录入口、激活输入、冷却/发送状态、额度/重置时间和错误使用自然分组；保留真实可用性。 |
| 模型准备与恢复 | 模型信息、进度、路径、停滞、取消、失败、诊断导出与运行时组件状态统一；处理阶段保持可见。 |
| 历史与删除 | 历史条目改用平面列表，保留状态/来源/时间/产物信息；删除确认保留危险语义、初始取消焦点与禁用原因。 |
| 笔记操作弹窗 | 重命名、添加到合集、笔记信息纳入相同外壳、标题、按钮和表单尺度，清理继承的模糊/渐变/阴影。 |

系统文件选择/保存窗口与外部浏览器中的登录页面继续由其所属系统管理；本次修改桌面客户端内的界面。

## 共同弹窗与未保存保护

- 共用外壳统一样式，保留 `AnimatedSheet` 的打开/关闭/隐藏生命周期、减少动态效果、焦点管理与背景 inert。
- 生成文字稿确认接入共同外壳和焦点管理，覆盖 Tab 循环、Escape、返回与入口焦点恢复；保持预选读取的取消保护。
- 草稿关闭与重新生成使用相同设计的应用内确认层，分别保留各自守卫。
- 放弃未保存修改只有明确确认后生效；取消、Escape、遮罩关闭保留编辑缓冲区、dirty 与原页面。
- 保存中继续阻止关闭和重新生成。确认层绑定发起时的任务身份，任务变化或请求失效时不能作用到其他任务。
- 重新生成的放弃确认通过后仍进入现有生成确认页，不直接启动生成；取消不提交、不保存、不扣除额度。
- 嵌套确认使用顶层焦点约束与逐层返回，避免 Escape 同时关闭两个层级。

## 业务与数据边界

保留全部真实控制器、任务身份、账号与额度门槛、云端内容告知、实际调用计费、输出语言快照、
确认/取消、进度、错误恢复、键盘与未保存保护、磁盘读取/保存/导出和历史数据语义。

本次不改变 worker、server、Tauri IPC、产物格式或隐私契约。正文继续通过现有消毒后的 Markdown
和结构化报告渲染。页面开关、全屏和预览/编辑切换不得清除现有缓冲区或启动后台操作。

## 验收要求

- 对最终真实渲染读取字号、行高、背景、边框、阴影、间距、滚动范围及控件命中区域；源码检查与测试结果分别记录。
- 视口覆盖 1734×907、1180×760、720×640 与 1734×640；覆盖三语、真实长标题/路径/内容、全屏及可达状态变化。
- 记录当前原生系统 DPR；额外 DPR/视口仿真独立标注，不将其宣称为其他系统显示缩放或多显示器验收。
- 三语验收可临时切换已有界面语言偏好，结束恢复原来的 system 或具体语言；保留其他用户设置。
- 使用真实鼠标、滚轮、键盘和 AX 检查可逆流程、焦点、滚动和操作区可达性。不得用滚动赋值代替输入证据。
- 通过既有回归覆盖状态分支；原生成功、下载、失败、余额限制和产物详情依据真实已有状态，缺项明确列出。
- 不注入账号、IPC、偏好、报告或任务状态；不移植网页样例，不创建演示历史，不为样式验收启动付费生成、下载或真实删除。
- 遵守 `RULES.md` 对主动视觉功能的限制。本次默认使用数值与输入验收；未获新授权的截图和像素视觉比较不视为已验证。
