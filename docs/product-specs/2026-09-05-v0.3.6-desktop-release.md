# FrameQ v0.3.6 Desktop Release

## Intent

Publish the current desktop source as v0.3.6 for the existing personal-development and small-user distribution scope. Include Xiaohongshu public platform subtitle reuse (including numeric format 0), account-bound self-service activation email UI and compatible server capability handling, transcript highlight/JSON robustness, and desktop fixes since v0.3.5.

## Boundaries

Platform subtitle hits skip ASR but retain existing video download/audio preparation. Missing or invalid subtitles fall back to existing ASR. No login-wall or CAPTCHA bypass, model weights, credentials, private configuration, or local outputs enter the release. Self-service activation depends on a compatible deployed server, SMTP and its existing rollout switch; this desktop release does not deploy or migrate production server data.

## Acceptance

Desktop versions agree at 0.3.6; local relevant suites and hosted server/macOS supervision gates pass; Windows installer/updater and both macOS DMGs build from the release tag. Release notes and task ledger record validation and native smoke limitations. Published runtime source must match main; any subsequent publication-ledger-only commit is explicitly identified.
