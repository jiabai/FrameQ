## 用户目标

用户在现有主页输入框粘贴公开或已授权的网页网址，FrameQ 加载页面、提取正文并保存为本地笔记。
保存结果进入现有笔记、合集和历史记录，重启及迁移后仍可读取。

## 已确认的界面范围

- 主页沿用当前布局，仅调整输入提示，说明同时支持视频链接和网页链接。
- 保持现有侧边栏、笔记列表、合集及整体页面布局。
- 网页处理阶段显示「加载网页 → 提取正文 → 保存笔记」，每个阶段反映真实工作，并保留取消及失败反馈。
- 网页笔记详情按 Markdown 展示正文，保留标题、段落、列表、引用、代码及表格等可安全表达的结构。
- 网页笔记隐藏音频播放器、时间戳和视频／音频定位操作。「定位文字稿」在网页笔记中显示为「定位正文」。
- 界面文字、状态、错误和辅助技术标签提供简体中文、繁体中文及英文。

## 保存内容与来源

- 一次成功保存包含网页标题、安全来源网址、UTC 提取时间、UTF-8 Markdown 正文和纯文本正文。
- 网页来源与媒体来源具有独立类型。网页正文不声明为 ASR 或平台字幕，不创建虚构音频、片段或视频产物。
- 提取到的网页标题作为默认笔记名称，手动重命名继续具有最高优先级。网页保存不触发媒体自动标题生成或 AI Credit 扣除。
- 已支持的视频网址继续进入现有视频流程；其他有效 HTTP(S) 网页网址进入正文流程。处理类型在 ASR 检查前确定。
- 原始请求网址仅在当前加载操作中使用。持久来源使用审查后的规范网址规则，移除 userinfo、片段、敏感或未授权的查询参数；日志、错误及云端请求不包含原始网址。
- 每次网页提交保存独立快照。再次提交同一网址不覆盖已有正文、用户修改、名称或合集成员关系。

## 本地笔记行为

- 正文产物保存在当前有效数据根的任务目录内，使用固定相对路径和类型。网页标题及网址不参与文件名生成。
- 网页笔记支持现有历史恢复、固定、重命名、加入合集、来源操作、笔记信息、文件定位及确认删除。
- 来源打开和正文链接仅在用户操作后经受控 HTTP(S) 打开。阅读本地笔记不执行网页脚本，也不自动请求外部图片、字体或其他资源。
- 提取时直接删除图片节点，不将图片alt/title写入生成的纯文本或Markdown，不插入「图片」或其他图片占位文字。
- 总结、脑图、灵感和解剖在用户明确确认后读取已保存的权威纯文本正文，沿用当前费用、额度、取消及失败保护。灵感草稿继续使用所选灵感、偏好快照和可选总结，原始正文不进入草稿提示。网页加载和保存本身不发起LLM调用。
- 原媒体笔记的文字稿、编辑、播放、模型准备、自动标题和智能提炼行为保持当前契约。

## 网页加载与提取

- 合法网页不因累计资源请求超过100个或同时待检查资源超过16个而失败。地址检查使用有界排队和背压；队列、时间或内存耗尽报告对应限额错误。
- 主页面和重定向到危险地址时终止。危险或加载失败的附属资源独立阻止；正文仍须经过真实导航完成、必要资源检查结束、DOM稳定和有效正文校验，不能把验证页面或空白结果保存为正文。
- 本地诊断只记录封闭枚举表示的拒绝原因和资源类别，不记录请求网址、域名、查询参数、Cookie或正文。

- 同时处理普通 HTML 页面和依赖 JavaScript 才产生正文的页面；正文提取使用实际页面 Document。
- 复用经过来源核查的 InsightFlow 正文选择、内容清理及 Markdown 转换逻辑，运行模块归属 FrameQ。
- 网页加载与主应用、账号配置、本地资源协议和用户浏览器会话隔离。页面脚本没有文件、Tauri IPC、账号或系统操作权限。
- 加载、提取和保存具有固定期限，DOM、正文和 Markdown 具有明确大小上限。取消使本任务结果失效并清理本应用拥有的宿主、保存进程和缓存；系统服务的控制范围按平台说明。
- 不导入浏览器登录状态，不执行登录，不处理 CAPTCHA，不绕过访问限制。受限页面、非 HTML、无可提取正文及超限页面返回明确失败。
- 页面 HTML 和提取结果均属于不可信内容。保存的 Markdown 与本地渲染不包含可执行 HTML、事件属性、危险链接或活动嵌入。
- 本应用创建的临时文件位于任务缓存目录；macOS 网站数据使用独立内存存储。系统 WebKit 服务及其自身资源由操作系统管理。
- 无法确认自有宿主、保存进程或自有缓存清理时，保留所有权记录并暂停该资料库的新数据操作。检查动作不清除本进程的暂停状态；受控重启后重新核验。

## 系统 WebView 约定

- Windows 使用已安装的系统 WebView2，macOS 使用系统 WKWebView；不为网页提取额外下载 Chromium、Playwright 或 Node driver。
- 删除「准备网页引擎」确认、下载进度和下载/展开空间说明。提交网页后直接显示加载阶段；缺失或不支持的系统能力通过既有失败状态说明，不启动浏览器安装。
- 远程页面运行于随应用交付的独立原生 helper；不复用主界面的 WebView 实例、用户数据目录、应用 IPC、插件或本地资源协议。
- 每次任务使用新的匿名网站会话，不导入主应用或用户浏览器登录状态。网页不获得 FrameQ 账号、本地文件或主界面操作权限。
- Windows 在现有桌面系统支持范围内检查 Stable WebView2 Runtime 与所需接口，最低版本为 143.0.3650.58。macOS 最低版本为14，使用公开的数据存储代理 API。已有笔记读取及智能提炼不依赖新建网页容器。
- 网络、内存和系统进程控制以[技术设计](../design-docs/2026-11-02-system-webview-extraction.md)的平台能力表为准；不承诺完整私网隔绝、全部网络统一配额或全部系统 WebKit 进程的精确强制回收，不新增系统级网络过滤扩展。
- 旧网页组件资料默认保留，停止下载、执行和探测；迁移及所有权恢复继续读取旧控制文件。新宿主使用独立版本和所有权记录，正文仍由现有 TaskStore 原子保存。

## 持久化与兼容

- Markdown、纯文本、来源元数据和 manifest 的发布具有原子性与恢复记录；未发布的材料不出现在笔记或历史中。
- 现有安全媒体任务继续可读。网页任务使用明确的版本和来源分支，损坏或未知版本不得被推断为有效笔记。
- 网页处理、保存、读取中的隐式恢复、删除和智能提炼受当前数据操作许可及任务修改保护约束。
- 数据迁移保留完整网页任务及合集关系，重启核验覆盖网页笔记，旧副本清理继续逐文件核对当前副本。
- 网页内容、正文、来源请求、页面 Cookie 和浏览器缓存不发送给 FrameQ 账号服务。

## 验收

- 真实静态页面和 JavaScript 延迟生成正文的页面均产生可重启读取的本地笔记，并保留段落、列表及其他规定结构。
- 同一输入框正确分流既有视频网址、网页网址及本地媒体；网页分支不检查、下载或运行 ASR 模型，不生成付费自动标题。
- 用户能从侧边栏、笔记列表和合集打开网页正文，定位正文文件，修改名称和成员关系，并通过既有确认流程删除。
- 页面尝试调用主应用 IPC、读取本地资源、启动下载或访问主应用账号/用户浏览器会话时，被相应原生与权限边界拒绝。
- 私网、WebSocket、WebRTC 等路径逐平台实测并记录能力；URL/DNS 检查不等同于全部真实连接均受拦截。
- 真实加载失败、无正文、超限、取消、处理超时、写入失败、进程中断及恢复不产生虚假成功；已有笔记内容保持完整。
- 真实文件与原生界面验证默认和迁移数据根、三种界面语言、Windows 与可用 macOS 环境；缺失环境的验证明确记录。
