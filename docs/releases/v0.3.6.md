# FrameQ v0.3.6

## 主要变化

- 小红书公开视频优先复用平台原声字幕，支持数字格式枚举 `0`；字幕可用时跳过 ASR，缺失或无效时保留原有 ASR 兜底。仍先下载视频、提取音频。
- 未激活或已过期账号可在兼容服务端支持下申请账号绑定的邮件激活码，再手动兑换；可用性取决于服务端版本、SMTP 与功能开关。
- 增强文字稿解剖的原文精确高亮与 JSON 提取，修复窗口拖动状态，并整理偏好持久化和文档。

## 下载

- Windows x64：`FrameQ_0.3.6_x64-setup.exe`
- Intel Mac：`FrameQ_0.3.6_x64.dmg`
- Apple Silicon Mac：`FrameQ_0.3.6_aarch64.dmg`

## 边界与验证

安装包不包含 ASR 权重、密钥或用户私有配置。公开平台访问限制保持不变。macOS 沿用 ad-hoc 签名，不宣称 Apple notarization。

本版本面向现有个人开发与小范围用户分发；不宣称已完成干净 Windows/macOS 机器的人工桌面验收。服务端生产部署和数据库迁移不包含在本次桌面发布中。具体自动化门禁与构建结果以发布计划和 GitHub Actions 为准。
