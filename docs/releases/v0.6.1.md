# Locus v0.6.1

## 主要变化

- **服务器换到了新域名 `locus.8xf.pro`**：旧域名 `frameq.8xf.pro` 已经停用，不再保留跳转或别名。
- **客户端默认服务地址跟着换**：登录、额度和结账默认走新域名。这一版**必须升级**，原因见下一节。

## 升级前请先看

- **v0.6.0 及更早的版本现在登录不上**。这些版本把旧域名写死在程序里，旧域名停用后，登录、额度查询和结账都连不上服务器。请从下载页安装 v0.6.1。
- 自动更新走 GitHub Releases，不受域名变化影响，所以 v0.6.0 能正常收到这一版；**v0.5.1 及更早的版本不在自动更新覆盖范围内**，需要手动下载安装。
- 版本号递增会让上一版已下载的可选 PyTorch 运行时组件失效，用 PyTorch 版语音模型的用户需要重新下载一次（约 140 MB）；默认 ONNX 模型不受影响。

## 下载

- Windows x64：`Locus_0.6.1_x64-setup.exe`
- Intel Mac：`Locus_0.6.1_x64.dmg`
- Apple Silicon Mac：`Locus_0.6.1_aarch64.dmg`

## 边界与验证

这一版只改服务地址，转写、整理、导出、数据目录与本地优先的行为都没有变化：视频、音频、文字稿、网页正文和模型缓存仍然全部留在本机，只有你确认的整理步骤才会把内容发出去。

服务器侧已完成切换并实测：新域名的证书签发覆盖 `locus.8xf.pro`，HTTP 全部 301 到 HTTPS，首页、下载页、隐私页、演示视频与 `/health/live` 均返回 200；nginx 配置里不再残留旧域名，旧域名的 DNS 记录已删除。

本次门禁：六处版本源一致为 0.6.1；前端、转写服务、服务端与脚本测试通过；文档校验 ERROR 与 WARN 均为 0。

## 已知局限

- 升级不会迁移旧数据目录，装过 FrameQ 时期的用户仍需按 v0.6.0 说明手动处理。
- macOS 安装包使用临时签名，未经过 Apple 公证，首次打开仍需手动放行。
- macOS Intel 验收任务需要手动触发，不随版本标签自动运行。
