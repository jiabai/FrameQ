# FrameQ v0.3.4

FrameQ v0.3.4 是一个桌面端补丁版本，更新应用图标并重新生成 Windows 与 macOS 安装包
所需的图标资源。除视觉标识和安装包元数据外，不改变转写、模型下载、任务处理或本地
数据行为。

## 下载选择

- Windows x64：`FrameQ_0.3.4_x64-setup.exe`
- Intel Mac：`FrameQ_0.3.4_x64.dmg`
- Apple Silicon Mac（M 系列）：`FrameQ_0.3.4_aarch64.dmg`

macOS 仍使用 ad-hoc 签名与 Gatekeeper 首次打开流程；本版本不宣称 Apple notarization 或
App Store 审核。

## 变更

- 更新 FrameQ 桌面应用图标及 Windows/macOS bundle 图标资源。
- 保持轻量安装包边界：不内置 ASR 权重、LLM key、云端模型或用户私有配置。

## 验证

- 版本源统一为 `0.3.4`。
- Desktop Release workflow 负责生成 Windows updater、Intel DMG 和 Apple Silicon DMG。
