# FrameQ v0.4.1

## 主要变化

- **新装后默认使用 ONNX 版 SenseVoiceSmall**：v0.4.0 的安装包虽然把 PyTorch 运行时移出了，首次启动写入的本地设置仍然指向 `iic/SenseVoiceSmall`，导致第一次转写会去下载 936 MB 的 PyTorch 权重，随后又因为缺少运行时组件无法开始识别。本版本修正了设置模板，新装用户直接走 ONNX，模型文件约 230 MB，安装包自带的运行时即可完成转写。
- **升级用户自动切换**：本地设置文件新增版本号。升级后首次读取配置时执行一次迁移，把旧模板写入的 PyTorch 模型名改为 ONNX，并记录版本号，后续不再重复改写。
- **显式选择仍然保留**：迁移完成后，在设置页重新选择 `SenseVoiceSmall` 会正常保存，不会被下次启动改回去。使用该模型前需要先在模型准备面板下载 PyTorch 运行时组件。
- **安装包内随附的设置模板同步修正**：安装包里的 `.env.template` 与首次启动生成的模板保持一致，两处都指向 ONNX。

## 下载

- Windows x64：`FrameQ_0.4.1_x64-setup.exe`
- Intel Mac：`FrameQ_0.4.1_x64.dmg`
- Apple Silicon Mac：`FrameQ_0.4.1_aarch64.dmg`

PyTorch 运行时组件（可选）：`frameq-pytorch-runtime-windows-x64.zip` / `frameq-pytorch-runtime-macos-x64.zip` / `frameq-pytorch-runtime-macos-arm64.zip`，由应用在设置中自动下载，一般不需要手动取。

## 边界与验证

安装包不含 ASR 权重、密钥或用户私有配置。本地优先边界不变：视频、音频、文字稿、模型缓存与本地历史仍全部留在本机。macOS 沿用 ad-hoc 签名，不宣称 Apple notarization。

验证情况：使用安装包自带的 Python 运行时完成 ONNX 模型下载（232 MB，校验文件正确），再把官方示例音频转成 16 kHz 单声道 WAV，走默认模型转写，输出内容正确，全程没有加载 PyTorch。前端 851 项测试、版本一致性检查与文档校验通过。

已知局限：本次只在 Windows 上完成了真实转写验证，macOS 两平台的验证依赖 CI 构建与手动触发的 `macos-intel-acceptance` 工作流，本次发版未自动覆盖。升级迁移不区分「旧模板写入」与「用户主动选择」，此前显式选过 `SenseVoiceSmall` 的用户也会被切到 ONNX，需要时可在设置页切回。
