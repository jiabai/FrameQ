# FrameQ v0.3.1

FrameQ v0.3.1 是面向个人开发、少量用户和开源工具场景的稳定桌面版本，支持 Windows
x64、macOS Intel 和 macOS Apple Silicon。本版本新增浏览器端 Web 用户控制台（账号与 AI
额度）、Server 页面中英切换、启发灵感 Profile v2 与本次生成偏好边界、进度感知的 AI
整理 watchdog、desktop worker contract v7 与文字稿解剖来源状态，并修复文字稿出处稳定性
（CRLF 字节级哈希一致）。视频、音频和文字稿仍默认在本机处理与保存，核心 ASR 模型仅在
用户提交已验证任务且所选模型缺失时下载。

## macOS 首次打开（下载前请阅读）

macOS DMG 使用 **ad-hoc 签名，未经过 Apple notarization（公证）**。这能验证应用包在
构建后未被修改，但不能建立 Apple Developer ID 身份。因此从 GitHub 下载后，macOS 会在
第一次启动时阻止直接打开。

当前 macOS 的推荐打开方式：

1. 将 FrameQ 拖入“应用程序”并尝试打开一次，然后关闭系统警告。
2. 打开 **系统设置 → 隐私与安全性**。
3. 找到 FrameQ 的拦截提示，点击 **仍要打开（Open Anyway）** 并再次确认。

macOS 14 及更早版本也可在“应用程序”中按住 Control 点击 FrameQ，选择“打开”。如果图形
界面入口不可用，可使用以下终端命令作为后备方式：

```bash
xattr -dr com.apple.quarantine /Applications/FrameQ.app
```

FrameQ 当前不宣称已通过 Apple 公证、App Store 审核或适合静默企业部署。macOS 更新采用
手动下载安装新版 DMG；Windows 继续使用现有签名 updater 元数据。

## 主要改进

### Web 用户控制台（账号与额度）

新增浏览器端 Web Dashboard（`/dashboard`）：使用与桌面端同一封邮件 OTP 登录，登录后可在
浏览器中查看账号邮箱、权益到期时间、AI Credits 限额/已用/剩余/重置时间、`can_process`、
`can_generate_ai` 和已绑定激活码前缀。桌面端登录成功页新增“登录成功”面板与“去到 Web
Dashboard”入口，桌面深链登录契约（`{ ticket, redirect_url }`）保持不变；Web 会话与桌面
会话相互独立，一处登出不影响另一处。同一 OTP 在桌面票据路径与 Web 会话路径之间只消费
一次。

### Server 页面中英切换

`/login`、`/dashboard`、`/admin/login`、`/admin` 四个页面新增语言切换按钮，在简体中文
（默认）与英文之间切换，选择通过非敏感 `lang` cookie 记住。本版本不提供繁体中文
Server 文案。

### 启发灵感 Profile v2 与本次生成偏好

灵感档案（Profile）精简为六项长期背景；表达风格与避免方向统一归入每次生成前的六步
本次偏好。本地偏好文件从 v1 原子迁移到 schema v2，仅在没有完整默认偏好时保留一次性
seed；当前重试快照在 JSON/Rust/Python 边界严格闭合，历史任务快照保持不变。

### 进度感知的 AI 整理 watchdog

AI 整理（RetryInsights）与文字稿解剖调用现在上报进度事件；watchdog 采用 30 分钟
validated-idle 与 90 分钟 absolute 双重 deadline，超时终止并 reap 完整进程树，且不自动
重试 LLM 或增加 AI Credits 调用。

### 文字稿解剖来源状态与 contract v7

desktop worker contract 升至 v7，AI 结果详情展示文字稿解剖的来源状态（含源文件过期等
边界处理），通过封闭结果协议传递，失败路径不回显载荷。

### 文字稿出处稳定性修复

修复含 CRLF 换行的文字稿在出处校验时字节不一致的问题：转录读取改为原始 UTF-8 字节后再
哈希，保证 `sourceTranscriptSha256` 与分段哈希和磁盘字节一致，文字稿解剖出处稳定。

## 隐私与安全

- Web 控制台页面不渲染会话 cookie、完整激活码或任何 LLM API key；Web 模式忽略调用方传入
  的任意 `redirect_uri`，只落在 `/dashboard` 或 `/login`，防开放重定向。
- Web 会话沿用 Admin Web 的 httpOnly session + CSRF double-token 模型；生产部署配置
  `secureCookies` 后会话 cookie 携带 `Secure` 标志。
- 安装包不包含 ASR 模型权重、LLM key、支付凭据、用户配置、日志、历史任务或用户产物。
- 微信支付仍未启用，`WECHAT_PAY_ENABLED` 继续默认关闭；当前授权方式仍是管理员发放的
  激活码。
- v0.2.17 接受的原子持久化、worker watchdog、server 鉴权/额度并发和 server 生产运维加
  固继续生效，本版本不重新触发各自的失败注入证据。

## 已知限制

- macOS：watchdog 运行时、locale/layout 物理验收、本地媒体导入和 ONNX VAD 流式均未在
  真实 macOS 主机实测；Windows 已记录对应验收证据。
- 启发灵感 Profile v2：原生打包启动未在受限环境实测，未消耗真实 AI Credit。
- 文字稿解剖：真实付费供应商 smoke 和原生打包跨平台 UX 未实测；自动化 worker、前端和
  Rust 门禁通过。
- Web 用户会话未绑定 IP/UA；被盗 cookie 在 90 天有效期内的可复用性与桌面会话 v1 持平。
- Server 语言切换不提供繁体中文，且首次访问英文用户需手动点击切换（无
  `Accept-Language` 回退）。
- AI 输出语言是 prompt 约束，供应商仍可能返回其他语言。FrameQ 不会自动检测、翻译或重试，
  也不会因此自动消耗额外 AI Credits。
- macOS 首次启动需要上述 Gatekeeper 手动授权，直到未来采用 Developer ID 签名与 Apple
  notarization。
- GitHub Releases 在部分网络环境中的下载速度可能较慢；macOS 不提供应用内自动更新。
- 外部视频平台页面或接口可能变化，公开链接下载能力仍受平台可用性影响。
