# FrameQ v0.4.0

## 主要变化

- **安装包小了约 370 MB**：语音识别用的 PyTorch 运行时（约 7,500 个文件、421 MB）不再随安装包分发，改为在你需要时单独下载。安装后实际落地的 Python 运行时从约 25,000 文件 / 950 MB 降到 16,810 文件 / 502 MB，解压与首次启动都更快。
- **默认模型改为 ONNX 版 SenseVoiceSmall**：它需要的运行环境随安装包提供，不必再单独下载运行时。模型文件仍在首次转写时按需下载，与以往行为一致。同一段 10 分钟访谈视频上，ONNX 转写耗时 46 秒，PyTorch 版 93 秒，文本相似度 0.90，差异集中在标点与断句，没有内容缺失。
- **需要 PyTorch 版时按需下载运行时组件**：模型准备面板新增「下载 PyTorch 运行时组件」按钮，组件约 140 MB，下载完成后即可切回 `SenseVoiceSmall`。组件带版本指纹校验，与本版本不匹配时会提示重新下载，不会复用旧文件。
- **组件缺失时会明确告诉你**：此前如果运行时不全，只会在转写阶段报一个通用失败。现在会区分「组件尚未下载」与「组件与本版本不匹配」，并给出对应操作。

## 下载

- Windows x64：`FrameQ_0.4.0_x64-setup.exe`
- Intel Mac：`FrameQ_0.4.0_x64.dmg`
- Apple Silicon Mac：`FrameQ_0.4.0_aarch64.dmg`

PyTorch 运行时组件（可选）：`frameq-pytorch-runtime-windows-x64.zip` / `frameq-pytorch-runtime-macos-x64.zip` / `frameq-pytorch-runtime-macos-arm64.zip`，由应用在设置中自动下载，一般不需要手动取。

## 边界与验证

安装包不含 ASR 权重、密钥或用户私有配置。本地优先边界不变：视频、音频、文字稿、模型缓存与本地历史仍全部留在本机。macOS 沿用 ad-hoc 签名，不宣称 Apple notarization。

升级用户的设置与历史保留；此前显式选过 `SenseVoiceSmall` 的用户，如果已下载过 PyTorch 运行时组件，升级后组件指纹会变，需要重新下载一次。

已知局限：长视频对比只有一条 10 分钟、单人讲述为主的素材，未覆盖强噪声、多人抢话与电话音质；ONNX 与 PyTorch 在断句粒度上的差异会随内容变化，不能按固定句数预期。macOS Intel 的完整验收仍靠手动触发的 `macos-intel-acceptance` 工作流，本次发版未自动覆盖。
