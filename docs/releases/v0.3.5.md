# FrameQ v0.3.5

FrameQ v0.3.5 是基于 v0.3.4 的桌面端补丁版本，重点增强 Motion 交互体验，并修复
Windows 本地 ASR 模型下载在 worker 启动阶段无法开始的问题。安装包仍保持轻量边界，
不内置 ASR 权重、LLM key、云端模型或用户私有配置。

## 下载选择

- Windows x64：`FrameQ_0.3.5_x64-setup.exe`
- Intel Mac：`FrameQ_0.3.5_x64.dmg`
- Apple Silicon Mac（M 系列）：`FrameQ_0.3.5_aarch64.dmg`

macOS 仍使用 ad-hoc 签名与 Gatekeeper 首次打开流程；本版本不宣称 Apple notarization 或
App Store 审核。

## 主要变化

### Motion 体验增强

- 处理阶段、任务状态、ASR 下载进度、AI 目标状态和历史列表拥有克制的状态变化动效。
- Account、Settings、History、ASR Model、AI Detail 以及确认流程的 Sheet 生命周期更平滑，
  并保留原有焦点、键盘和可访问性行为。
- 点击“重新开始新任务”返回输入页时，输入区增加短暂的淡入上移动效；首次打开首页不播放
  该重置专属动效。
- 所有 Motion 动效继承用户的 reduced-motion 偏好，不阻塞输入和任务重置。

### ASR 下载启动稳定性

- Windows 开发启动器会在启动 Tauri 前补齐本地 Python runtime 所需的 VC++ 运行库 DLL。
- worker 启动前进行 app-local 运行库自检，区分运行库缺失与模型传输失败，避免出现“下载失败”
  但实际下载动作从未开始的模糊状态。
- 保留模型按需下载、缓存、取消、失败降级和离线行为边界；启动应用时不会自动下载模型。

## 验证

- 版本源统一为 `0.3.5`。
- Windows 桌面烟测通过：模型下载启动路径和“重新开始新任务”交互可用。
- 前端完整测试、lint、生产构建和治理文档校验已执行；Desktop Release workflow 负责生成
  Windows updater、Intel DMG 和 Apple Silicon DMG。
