# Locus v0.6.0

## 主要变化

- **名字改为 Locus**：产品统一叫 Locus，不再使用「影问」这个中文名。窗口标题、界面文案、安装包文件名、安装目录与日志文件名都跟着换了。

- **内部命名不再带产品名**：程序包名、环境变量、配置文件、任务落盘文件、诊断包与可选组件包都改成按用途命名。以后再换名字，只需要改几处显示用的常量，不会碰到数据文件。

- **本地优先不变**：视频、音频、文字稿、模型缓存与本地历史仍全部留在本机；只有你确认的整理步骤才会把文字发出去。

- **可以填自己的模型服务**：设置里新增「模型」页，能添加你已有账号的服务、先测试连接再保存，密钥只存在系统钥匙串里。默认仍用 Locus 提供的服务，自己添加的服务不扣内置额度。

- **整理失败时说清原因**：网络不通、服务里没有所选模型、额度不够等情况分别给出提示，可以照着提示直接处理。

- **合集整理更顺手**：把笔记加进合集后，它仍留在原来的笔记列表里；添加清单会标出「已在此合集」，加入或移出后给出一句说明和一个撤销按钮。

- **换数据位置更快**：迁移大量本地资料时并行复制与核对，等待时间更短。

## 升级前请先看

这一版改了应用标识，所以对装过旧版（FrameQ v0.5.1 及更早）的机器来说，它是一次**全新安装**，不是原地升级：

- 旧版不会被自动卸载。装完可能同时看到两个图标，建议先手动卸载旧版再装这一版。
- 旧版的笔记、处理记录与设置不会自动带过来。新版本使用新的数据目录，从空库开始；需要保留的内容请先从旧版导出，或手动把旧数据目录搬到新目录。
- 旧版的自动更新不会推送这一版，请从下载页手动安装。
- 如果你用的是可选的 PyTorch 版语音模型，升级后需要重新下载一次运行时组件（约 140 MB）；默认模型不受影响。

## 边界与验证

安装包不含语音识别权重、密钥或用户私有配置。改名只影响名称与标识，不改变转写、整理、导出等既有功能的处理方式；本机启动复验确认窗口标题、登录提示、数据目录与日志文件名都已切换到新名字，且能正常退出。自己添加的模型服务，密钥只写入系统钥匙串，不进入配置文件与日志。

本次门禁：前端 1591 项通过（1 项跳过），转写服务 1332 项通过（4 项跳过），服务端 375 项通过（1 项跳过），Node 脚本 57 项与 Python 脚本 1 项通过，文档校验 ERROR 与 WARN 均为 0，桌面端、服务端与营销站生产构建通过，六处版本源一致为 0.6.0。合集的加入、移出与撤销在 Windows 原生窗口用真实指针与键盘做过三种语言各 17 项验收（累计 51 项）。Rust 全量测试与三个平台的安装包由发布构建覆盖。

## 已知局限

- 旧数据迁移与旧版自动卸载都没有做，需要按「升级前请先看」手动处理。
- macOS 安装包使用临时签名，未经过 Apple 公证，首次打开仍需手动放行；macOS 图形交互、首次打开的权限与 Gatekeeper 交互尚未在真机完成验收。
- macOS Intel 验收任务需要手动触发，不随版本标签自动运行。
- 内部验收安装包关闭了自动更新的签名校验文件，公开的签名更新链路未做端到端实测。
- 域名、仓库地址与服务器部署路径仍使用旧名，属于后续运维迁移，不影响本机功能。
