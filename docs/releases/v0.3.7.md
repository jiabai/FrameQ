# FrameQ v0.3.7

## 主要变化

- 抖音分享页解析加入有界重试：单次解析失败后随机等待 3 到 10 秒再试，最多 3 次，减少分享页偶发降级把整个任务带失败的情况；重试期间会显示「正在重试解析抖音分享页」。此改动只作用于分享页解析这一步，视频下载、音频准备与语音识别流程不变。
- 账号面板的激活码标题由「输入管理员发放的激活码」改为「输入你的激活码」（三语同步），与同屏已有的「领取激活码」按钮不再互相矛盾——激活码既可以是管理员发放的，也可以由你自助领取。
- 文案与文档整理：面向用户的隐私说明与常见问题统一为普通读者能读懂的说法。

## 下载

- Windows x64：`FrameQ_0.3.7_x64-setup.exe`
- Intel Mac：`FrameQ_0.3.7_x64.dmg`
- Apple Silicon Mac：`FrameQ_0.3.7_aarch64.dmg`

## 边界与验证

安装包不包含 ASR 权重、密钥或用户私有配置。公开平台访问限制保持不变。macOS 沿用 ad-hoc 签名，不宣称 Apple notarization。

重试会增加最坏情况下的等待时间（每次 3 到 10 秒，最多 3 次），但不改变最终失败时的用户可见结果；分享页重试目前不产生独立的诊断事件，导出的诊断包无法区分「首次成功」与「重试后成功」，属已知残余项。本版本面向现有个人开发与小范围用户分发，不宣称已完成干净 Windows/macOS 机器的人工桌面验收。服务端生产部署与数据库迁移不包含在本次桌面发布中。具体自动化门禁与构建结果以发布计划和 GitHub Actions 为准。
