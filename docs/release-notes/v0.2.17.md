# FrameQ v0.2.17

FrameQ v0.2.17 是面向个人开发、少量用户和开源工具场景的稳定桌面版本，支持 Windows
x64、macOS Intel 和 macOS Apple Silicon。本版本打包了桌面端国际化与 AI 输出语言行为，
同时完成了服务器认证/额度并发和生产运维加固。视频、音频和文字稿仍默认在本机处理与
保存；核心 SenseVoice Small 模型在首次使用时下载，不包含在安装包中。

## macOS 首次打开（下载前请阅读）

macOS DMG 使用 **ad-hoc 签名，未经过 Apple notarization（公证）**。这能验证应用包在
构建后未被修改，但不能建立 Apple Developer ID 身份。因此从 GitHub 下载后，macOS 会在
第一次启动时阻止直接打开。

当前 macOS 的推荐打开方式：

1. 将 FrameQ 拖入"应用程序"并尝试打开一次，然后关闭系统警告。
2. 打开 **系统设置 → 隐私与安全性**。
3. 找到 FrameQ 的拦截提示，点击 **仍要打开（Open Anyway）** 并再次确认。

macOS 14 及更早版本也可在"应用程序"中按住 Control 点击 FrameQ，选择"打开"。如果图形
界面入口不可用，可使用以下终端命令作为后备方式：

```bash
xattr -dr com.apple.quarantine /Applications/FrameQ.app
```

FrameQ 当前不宣称已通过 Apple 公证、App Store 审核或适合静默企业部署。macOS 更新采用
手动下载安装新版 DMG；Windows 继续使用现有签名 updater 元数据。

## 下载选择

- Windows x64：`FrameQ_0.2.17_x64-setup.exe`
- Intel Mac：`FrameQ_0.2.17_x64.dmg`
- Apple Silicon Mac（M 系列）：`FrameQ_0.2.17_aarch64.dmg`

不提供 Linux 安装包，也不提供 Universal macOS 单包。

## 主要改进

### 桌面端国际化

- 新增简体中文、繁体中文和美式英语三语 UI 资源，支持持久化语言偏好，不支持的系统
  区域设置确定性回退到英语。
- 本地化覆盖设置、账户、历史、文字稿、AI 工作区、进度、无障碍、已知错误和安全技术
  详情等全部应用自有界面。
- 用户确认生成"智能提炼"或"启发灵感"时，冻结当前 UI 语言并通过严格 desktop-worker
  契约传递闭合语言枚举，确保 AI 输出语言与用户选择一致。
- 完成"AI 整理"到"智能提炼"的工作区命名变更。

### 可靠性加固

- **原子持久化**：所有权威文字稿、AI 产物、偏好和 task manifest 采用同目录单文件原子
  替换；现有任务多文件 transaction recovery、故障注入矩阵和跨语言 journal 契约通过验证。
- **Worker watchdog**：所有受监督 worker 操作拥有 Rust 运行时拥有的固定绝对 deadline；
  具有闭集进度协议的操作还拥有 validated-progress idle deadline。超时终止并 reap 匹配的
  完整进程树，覆盖正常完成、静默、进度后停滞、阻塞 stdin、structured-result/cancel/
  timeout race、stale instance 和第二任务启动。
- **服务器认证/额度并发**：OTP purpose、attempt、artifact 和 ticket/session 由语义 Store
  事务原子提交；额度使用数据库条件更新和唯一 request event，由独立 Prisma client 连接
  证明不重复、不超额和故障回滚。
- **服务器生产运维**：production SMTP/必需 secrets fail closed；结构化日志通过
  secret-seeded 脱敏测试；live/ready 状态真实；SIGTERM 实际 drain Fastify 并断开 Prisma；
  SQLite 生产变更使用已审查 baseline + forward migration，且有 preflight、停机备份、
  checksum/权限/异地留存、隔离 restore 和 `PRAGMA integrity_check` 证据。

### 其他

- 新增 Node.js 24 兼容的 GitHub Actions 维护。
- 新增严格受控的历史任务永久删除（v0.2.16 引入，继续保留）。
- 安装包不内置 ASR 权重、LLM key、云端 LLM 模型或用户私有配置；核心本地 ASR 模型
  （首版为 SenseVoice Small）由首启引导下载。

## 隐私与安全

- 原始 source URL 只通过受控 stdin 请求进入当前 worker，不进入子进程 argv、环境变量、
  manifest、历史、日志、文字稿、缓存键或 LLM prompt。
- 所有持久化来源身份继续使用 canonical SourceIdentity；仅当前安全 schema v3 历史任务可
  展示、读取、缓存复用、编辑或 retry。
- 不兼容的旧历史目录不会被自动迁移、读取或删除；如需保留或清理，请在产品外自行备份或
  删除。
- 安装包不包含 ASR 模型权重、LLM key、支付凭据、用户配置、日志、历史任务或用户产物。
- 服务器生产日志和公共响应不含 OTP、邮箱地址、token、密钥、数据库路径或用户数据。

## 已知限制

- macOS 首次启动需要上述 Gatekeeper 手动授权，直到未来采用 Developer ID 签名与 Apple
  notarization。
- Apple Silicon 安装包具有 GitHub 托管构建、运行时导入和签名完整性验证，但本次发布报告
  仍会区分自动化证据与真实物理设备验收。
- GitHub Releases 在部分网络环境中的下载速度可能较慢；macOS 不提供应用内自动更新。
- 微信支付尚未启用或联调，`WECHAT_PAY_ENABLED` 继续默认关闭；当前可见授权方式仍是管理员
  发放的激活码。
- 外部视频平台页面或接口可能变化，公开链接下载能力仍受平台可用性影响。
- 真实 LLM 提供方可能忽略 best-effort 输出语言指令；FrameQ 不检测或翻译不匹配的输出，
  也不会自动额外消耗 AI Credits。
- 本地视频/音频文件导入功能已实现并通过 Windows 验收，但不在 v0.2.17 发布范围内。
