# macOS 打包应用原生 UX 实测清单

**日期：** 2026-08-23
**状态：** 待目标 Mac 执行（本机 Windows 无法驱动 macOS 原生界面，此清单供在真实 macOS 上照做）
**对应残余：** v0.3.0「native packaged cross-platform UX」的 macOS 未验证部分（Windows 侧证据已记录；网页层交互已被 `app/tests/app-input.browser.test.ts` + jsdom 测试覆盖，无需重测）

## 为什么要有这份清单

FrameQ 的界面是 Tauri 壳 + 网页（React）。网页层行为（点卡片、走偏好流、出结果）是跨平台一致的，已经用无界面浏览器测试锁住了。但下面这些**原生外壳行为**只在 macOS 上真实发生，任何无界面测试都代替不了：

- 自绘的红黄绿窗口按钮（`decorations:false` 下，会不会和系统按钮重叠、点了有没有反应）
- 标题栏拖拽（高刷屏下会不会抖、松手是否停止）
- 原生「打开文件 / 保存」对话框（未公证、ad-hoc 签名下能不能弹、能不能写盘）
- 取消任务时真正杀掉 Python 子进程树（会不会残留僵尸进程）
- macOS 无内置更新、不注册 deep link 的降级行为

## 前置准备（测前三件事）

1. 一台真实 Mac（Intel 或 Apple Silicon 均可，对应下载 x64 / arm64 DMG）。
2. 从 [GitHub Releases](https://github.com/jiabai/FrameQ/releases) 下载最新 DMG，拖入「应用程序」后**从访达打开**（不要用 `open` 命令绕过 Gatekeeper，要复现真实首次启动）。
3. 登录账号、确保有额度；首次使用会让 worker 下载 ASR 模型（这是验证 macOS 上 worker 能正常 spawn 的第一个信号）。

> 记录项统一填：`✓ 通过 / ✗ 失败 / — 未测`，失败写明现象和截图路径。

## 一、三大功能端到端（网页层，已在 CI 覆盖，这里只确认「在打包应用里也能跑通」）

前提：先用一个真实抖音/B 站视频链接跑完转写，得到文字稿，三张卡片才会变成可点。

| # | 功能 | 操作步骤 | 预期结果 | 失败判据 |
|---|---|---|---|---|
| 1.1 | 要点总结 | 点「要点总结」卡片 → 偏好流里确认生成 | 卡片进入生成态，随后出现总结 + 脑图 | 卡住、报错、白屏、控制台报错 |
| 1.2 | 启发灵感 | 点「启发灵感」卡片 → 走六步偏好 → 生成 | 出灵感卡片（主题/匹配理由/启发问题） | 同上；或偏好流无法前进 |
| 1.3 | 文字稿解剖 | 点「文字稿解剖」卡片 → 预览确认 → 生成 | 出解剖报告（段落/亮点/受众适配） | 同上；或预览额度算错、确认按钮灰死 |

每一条都要顺带确认：**worker 真的起来了**（活动监视器里能看到 `python3`/`frameq_worker` 进程），结果写到了 app-local 输出目录。

## 三、原生文件对话框

| 3.1 | 打开文件 | 输入卡点附件图标 → 选「本地文件」 | 弹出**系统**文件选择器，选一个视频/音频后正确导入（显示文件名/时长） | 弹不出、闪退、选中后无反应 |

> 3.1/3.2 是 ad-hoc 签名、**未公证**的应用，重点关注首次弹对话框时 macOS 是否要求额外授权、授权后能否正常读写。

## 四、取消与进程回收

| # | 触点 | 操作步骤 | 预期结果 | 失败判据 |
|---|---|---|---|---|
| 4.1 | 取消 AI 生成 | 生成进行中点「取消」，等状态回到就绪 | UI 回到可重试；活动监视器里对应 `python3` 进程消失 | 进程残留（僵尸）；UI 卡在「取消中」 |
| 4.2 | 取消转写 | 转写进行中点取消 | 同上，worker 进程树整体退出 | 残留 `ffmpeg`/`python` 子进程 |
| 4.3 | 超时回收 | 触发一次 watchdog 超时（或等长任务超时） | 显示本地化的超时恢复提示，不留死进程 | 进程泄漏、无提示 |

> 关键点：macOS 走的是 unix 进程组 `kill -TERM` → 500ms → `kill -KILL`，务必确认能**整树杀掉**，而不是只杀父进程留孤儿。

## 五、平台降级行为

| # | 触点 | 操作步骤 | 预期结果 | 失败判据 |
|---|---|---|---|---|
| 5.1 | 无内置更新 | 设置里找「检查更新」 | macOS 上**不出现**应用内更新流程，直接跳浏览器打开 releases 页 | 出现应用内更新 UI；点更新没反应 |
